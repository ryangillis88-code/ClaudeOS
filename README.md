# ClaudeOS

Personal operating system built on Claude — projects, templates, skills, and outputs all in one place.

## Structure

| Folder | Purpose |
|--------|---------|
| `_core/` | About me, goals, and memory files Claude reads for context |
| `inbox/` | Drop files here for Claude to process |
| `projects/` | Active projects (property app, daily debrief, fantasy football, ideaverse) |
| `templates/` | Reusable document and prompt templates |
| `skills/` | Custom Claude skills |
| `outputs/` | Generated files, reports, and debriefs |
